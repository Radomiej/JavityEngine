This tests the harness only, not Android runtime.

- [x] **BUG-CI-003 / P2 — cross-version SQLite serialization broke the fixture gate.** Remote [39042304941](https://github.com/Radomiej/JavityEngine/actions/runs/39042304941) compared town.mbtiles bytes including SQLite version header. Compare schema, metadata and exact tile blobs, while validating each package's own SHA manifest. Only the MBTiles hash differs between manifests. Regression accepts an altered SQLite version header, but still rejects altered tile bytes and metadata with refreshed hashes. Eighteen map tests pass locally; no fixture data changed.

Independent Chromium verification passes at widths360/390/768/1440; images, commands, keyboard tabs and mobile navigation work, with no observed browser errors. The harness passes simulated Gradle status37 and0 while preserving diagnostics. These checks do not constitute Android runtime execution.
