# Shapes AA Implementation Plan

> Agentic workers: Superpowers subagent-driven-development; user explicitly selected Luna agents. No commits/push in this repo.

**Goal:** Antialiased circle/rectangle/polyline with robust alpha and zoom in the existing desktop engine.
**Architecture:** SDF backend owns GPU resources, ShapeRenderer2D owns data/styles, root keeps renderer order and integrations. Independent demo proves actual GL pixels.
**Tech Stack:** Java25, libGDX1.14.2, GLSL desktop derivatives, JUnit4, Xvfb/Mesa.
**Spec:** ../specs/2026-10-14-shapes-aa-design.md

## Global Constraints
- Preserve all previous workspace modifications; no commit/push.
- No Unity/Shapes dependency, no mesh/shader allocation each frame.
- Exactly 64 effective polyline points max, explicit error; round joins only.
- Stroke centered in local units, WORLD/SCREEN, AA ~1 screen pixel via fwidth.
- Polygon keeps legacy non-AA triangulation.

## Review Focus
- Nonuniform or zero scale: valid smooth fringe or skip, no clipped quad.
- Duplicate/zero-length segments: defined cap behavior, no NaN shader data.
- Transparent joints: union coverage, no alpha accumulation from multiple passes.
- Existing JSON scenes: defaults and round-trip, stable style names.
- Render state/layer order: sprites/text/UI unchanged; screen after world.
